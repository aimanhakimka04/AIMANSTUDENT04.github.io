## 🚀 Getting Started

### View Live
Visit the live site at:
```
https://aimanstudent04.github.io
```

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/aimanhakimka04/AIMANSTUDENT04.github.io.git
   ```

2. **Open `index.html`** in your browser
   ```bash
   # Windows
   start index.html

   # macOS
   open index.html

   # Linux
   xdg-open index.html
   ```

No build steps, no dependencies — it just works!
